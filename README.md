# Tejas Thakare — Personal Portfolio Website 🚀

A high-performance, pitch-black Awwwards-inspired editorial personal portfolio website built with **React 19**, **Vite 8**, **Tailwind CSS 4**, and **Framer Motion 13**.

---

## 🌟 Key Features

- **Pitch-Black Monochrome Editorial Theme**: High-contrast Awwwards-inspired layout with pure obsidian backgrounds (`#000000`) and crisp white typography (`#ffffff`).
- **Responsive Mobile Layout**: Custom editorial mobile layout with sticky floating glass dock navigation.
- **Interactive PDF Resume Viewer**: Embedded CV modal with direct download and new-tab PDF view fallback (`TEJAS_THAKARE_R.pdf`).
- **Live Project Showcase**: Interactive cards featuring live web applications (*Discover Nashik Tourism*, *Nashik's Best Misal*, *Fly Ash Bricks Industrial ERP*).
- **Anti-Gravity Physics Sandbox**: Interactive canvas arcade with physics collision mechanics.
- **SEO & Social Optimization**: Built-in meta tags, OpenGraph attributes, and fast asset loading.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite 8.2, Tailwind CSS 4, Framer Motion 13, React Icons
- **Deployment Target**: Vercel / Netlify / GitHub Pages
- **Asset Processing**: PostCSS, Autoprefixer

---

## 🚀 Local Setup & Development

```bash
# 1. Clone the repository
git clone https://github.com/Tejas143220/tejas-portfolio.git
cd tejas-portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build locally
npm run preview
```

## 🌐 Deploy to Production (Vercel)

This project is 100% **Ready for Deployment**!

### Option 1: Deploy via Vercel CLI
```bash
npm i -g vercel
vercel
```

### Option 2: Deploy via Vercel Dashboard
1. Push your code to **GitHub**.
2. Import repository into [Vercel Dashboard](https://vercel.com/new).
3. Framework Preset: **Vite**.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Click **Deploy**! 🎉
